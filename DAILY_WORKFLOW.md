# Daily delivery cycle

Read AGENTS.md, BACKLOG.md, README.md, branch, recent commits and any issue notes. Review yesterday's implementation for correctness, security, responsive behavior, accessibility and unfinished edge cases. Fix findings, then implement the scheduled backlog item. Add or update focused tests for prior and current behavior. Debug the affected path and run lint, typecheck, relevant tests and production build. Check touched screens at phone, tablet and desktop widths and in both themes. Update docs, data notes and backlog, add discoveries with priority/acceptance criteria, and leave a concrete next-day handoff. Commit only reviewed work; push the named branch when its remote/auth is configured. Record command outcomes and blockers without claiming unverified success.
